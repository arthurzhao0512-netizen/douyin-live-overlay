# 抖音弹幕悬浮窗

给用「抖音直播伴侣」打游戏直播的主播用的小工具（仅 Windows）：

- **自己屏幕上**：一个透明、鼠标点不到的悬浮窗，只显示弹幕（带抖音表情）、礼物和在线观众，不会误触，不挡游戏操作
- **直播画面里**：把弹幕、礼物，以及「大啤酒」「美味烧鸡」的全屏礼物特效，通过两个隐藏的捕获窗口送进直播伴侣
- 可以和直播伴侣一起启动、一起退出

> 弹幕是通过在后台打开你的直播间网页、读取网页自己收到的数据获得的，不需要任何抖音接口密钥。

## 需要准备

- Windows 10 / 11
- [Python 3.10 或更新版本](https://www.python.org/downloads/)（安装时一定要勾选 **Add python.exe to PATH**）
- Microsoft Edge（Windows 自带）
- 抖音直播伴侣

## 第一次使用

1. 下载本仓库（右上角绿色 **Code → Download ZIP**），解压到一个固定的文件夹
2. **双击 `start.bat`**：第一次会自动安装需要的组件（playwright、pystray、pillow），然后问你的直播间网址或房间号，填一次就会记住
3. 如果你的直播设了「部分人可见」，先**双击 `login.bat`**，在弹出的 Edge 窗口里扫码登录抖音，登录好后关掉那个窗口
   - 建议用**小号**登录：同一个抖音账号在手机上看别人直播时，会把这里的弹幕连接挤掉

启动后，屏幕右下角托盘里会出现一个红色气泡图标，所有功能都在它的右键菜单里。

## 把弹幕和礼物特效放进直播画面

1. 托盘右键 → 勾选「直播捕获窗口」和「特效捕获窗口」，会出现两个绿色窗口
2. 在直播伴侣里 **添加素材 → 窗口**，分别选：
   - `pythonw.exe 抖音弹幕 - 直播捕获`（弹幕 + 礼物 + 在线观众）
   - `pythonw.exe 大啤酒特效 - 抖音弹幕`（礼物全屏特效）：**拉大铺满整个画面**
3. 给这两个素材开「抠图 / 绿幕」，抠掉绿色
4. 托盘里勾选「藏起捕获窗口」：两个窗口会变得完全透明、鼠标能穿过，桌面上看不到，直播画面照常
5. 托盘里点「发一条测试弹幕」「测试大啤酒特效」「测试美味烧鸡特效」检查效果（**测试会出现在直播画面里**）

> 两个捕获窗口不要最小化、不要拖到屏幕外面，否则直播画面会卡住。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| Ctrl + Alt + D | 显示 / 隐藏自己屏幕上的悬浮窗 |
| Ctrl + Alt + E | 移动模式：拖动悬浮窗，再按一次保存位置 |

## 设置

所有设置都在 `overlay_config.json` 里（第一次运行后自动生成），托盘右键「打开设置文件」修改，改完点「重新加载设置」。常用的：

| 设置 | 说明 |
|---|---|
| `room_url` | 直播间地址 |
| `font_size` / `width` / `max_lines` | 字号、宽度、最多显示几条 |
| `expire_seconds` | 弹幕显示多少秒后消失 |
| `keep_recent` / `keep_recent_count` | 一直显示最近几条弹幕 |
| `effect_gifts` | 哪些礼物播放全屏特效，例如 `{"大啤酒": "beer", "美味烧鸡": "chicken"}` |
| `effect_screen_size` / `effect_screen_pos` | 自己屏幕上特效的大小、位置（托盘里也能改） |

## 和直播伴侣一起启动（可选）

想点一个图标同时打开直播伴侣和悬浮窗，并且直播伴侣关闭时悬浮窗自动退出：新建一个快捷方式，目标填

```
pythonw.exe "<本文件夹>\danmaku_overlay.py" --with-companion
```

程序会自动从开始菜单找到直播伴侣；找不到时，在设置里把 `companion_path` 填成「直播伴侣 Launcher.exe」的完整路径。

## 常见问题

- **一直显示「还没收到弹幕」**：直播间没开播，或者直播设了「部分人可见」但还没运行 `login.bat` 登录
- **直播画面里的素材变成一条细线 / 内容不对**：删掉素材重新添加一次
- **出了问题**：托盘右键「查看运行日志」

## 说明

- 仅供个人直播辅助使用，弹幕数据来自你自己的直播间网页
- 礼物特效（啤酒杯、烧鸡等）是程序自己画的原创卡通图案
- 运行时下载的抖音表情图片只保存在本机，不包含在本仓库里
